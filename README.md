# RentEase

RentEase is a responsive furniture and appliance rental platform prototype for students and working professionals who relocate often.

## Included flows

- Browse furniture, appliances and move-in bundles by budget and category.
- Build a rental cart with monthly rent and refundable deposit estimates.
- Schedule delivery with a date, city, time slot and address.
- Review active rentals, request extensions and view rental history.
- Submit maintenance requests and inspect a support tracker.
- Switch to the admin workspace to monitor inventory, delivery, maintenance and returns.

## Run locally

Open `index.html` in a browser. This is a static HTML, CSS and JavaScript prototype, so no build step is needed.
